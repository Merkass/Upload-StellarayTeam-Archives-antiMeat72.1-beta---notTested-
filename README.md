## 📋 Описание

AntiMeat — это комплексный дата-пак для защиты серверов Minecraft от различных видов читерства и нежелательного поведения игроков. Система обеспечивает строгий контроль игрового процесса и автоматически наказывает нарушителей.

## ⚡ Основные возможности

### 🚫 Блокируемые действия:
- **Режимы игры**: Креативный, Спектатор, Выживание (принудительный режим Приключения)
- **Прыжки**: Полный запрет прыжков с наказанием
- **Выбрасывание предметов**: Автоматическое удаление выброшенных предметов
- **PVP**: Блокировка урона между игроками с исцелением

### 🛡️ Система наказаний:
- Автоматическая смена режима игры
- Эффекты замедления и слабости
- Телепортация и ослепление нарушителей
- Мгновенное исцеление жертв PVP

### 🔓 Система обхода:
Администраторы и доверенные игроки могут получить тег `BypassAntiMeat` для обхода всех ограничений.

## 📦 Установка

1. Скачайте дата-пак
2. Поместите папку `AntiMeat` в директорию `datapacks` вашего мира
3. Перезагрузите мир или выполните `/reload`
4. Система активируется автоматически

## 🎮 Использование

### Для администраторов:

**Дать обход защиты:**
```
/tag <игрок> add BypassAntiMeat
```

**Убрать обход защиты:**
```
/tag <игрок> remove BypassAntiMeat
```

**Перезагрузка дата-пака:**
```
/reload
```

### Для игроков:
После установки все игроки автоматически переводятся в режим Приключения. Любые попытки нарушить правила будут пресечены с соответствующими наказаниями.
